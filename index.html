Backend development

Jakarta EE at university built the foundation, and Spring Boot is now the main framework. ArejeKota is a multi-vendor food ordering REST API built with Spring Boot, Spring Data JPA and MySQL, organised into controllers, services, repositories and DTOs.

It includes email OTP account activation, BCrypt password hashing, JWT login and a vendor onboarding flow with admin approval. Orders and role-based security are in progress.

Data analytics

A 255,000-row financial dataset was cleaned and analysed in Python with Pandas to find which borrower characteristics lead to loan defaults. Default rates fall from 20.56% for ages 18 to 25 to 4.60% for ages 65 and over, and applicants earning under 30k default at 21.96% against 9.05% for those above 110k.

Security and networking

Cryptography (DES, AES, hashing) and networking were studied in theory, with Cisco Packet Tracer used to practise network design. The hashing side shows up in ArejeKota through BCrypt.
